# 纸上诗意 · 图片生成

## 目标与边界
将输入主题转译为原创插画，保持下述视觉体系。固定颜色关系、材质、空间节奏和字体气质；根据主题重新发明主体、动作、视角、位置与叙事。不得重现参考图的花枝、动物姿态、树群位置、封面文字或完整布局。不要以艺术家姓名作为生成提示词，不要输出“某某艺术家同款”。
仅在用户明确要求修改风格时改变规则。主题中出现“科技、城市、机械、运动”等内容时仍按本体系绘制，不自动切换到写实摄影、赛博霓虹、3D 或商业渐变。

## 共同视觉规律与固定规则
### 1. 配色：有力度的纸上颜色
参考图包含明亮黄底、蓝底、砖红底与绿底，不把风格误解成统一浅米色或低对比莫兰迪。
使用以下近似工作色值；这是根据参考图建立的设计色标，不是精确取样或要求像素一致。

| 色彩角色 | 工作色值 | 用途 |
|---|---|---|
| 纸米白 | #F3EED8 | 主体、花瓣、呼吸空间 |
| 天空蓝 | #78B9D4 | 开阔背景、轻盈色块 |
| 矿物深蓝 | #17617B | 深背景、空间层次 |
| 金黄 | #E9B323 | 温暖背景、小面积强调 |
| 植物绿 | #578344 | 主体、中间色 |
| 黄绿 | #AFBE51 | 叶片或明亮对比色 |
| 青绿 | #83B9A4 | 冷暖过渡、辅助形体 |
| 砖红 | #A65340 | 背景或节奏性点色 |
| 深墨绿 | #233C31 | 枝干、轮廓、文字 |

每张选 1 个背景主色、2–3 个主体/辅助色，加米白与深墨绿；避免同时平均使用全部颜色。背景约占 45–65%，主体与辅助色约占 30–50%，强点色约占 2–8%，允许随内容微调。保留温冷或明暗对比，但用纸纹与颜料颗粒柔化色块，禁止荧光色、塑料纯亮色、金属高光与光滑渐变。

### 2. 插画：简练形体与明显印刷颗粒
用简化、略不规则的剪纸式轮廓与平涂形体。重点是色块内部清楚可见的印刷颗粒、斑驳漏白、干刷断续和不均匀着墨；不能只加一层细微纸纹就称为版画质感。让颗粒有粗细与密度变化，背景也保留可见颜料沉积与纸纤维，缩小看仍能感到手工印刷的粗粝。
营造木刻、孔版印刷、干粉颜料与纤维纸相交的质感；不是实际印刷工艺鉴定。保留清楚的大形体边界，不能用统一数字噪点、脏污滤镜或破损做旧代替真实材质。
采用近乎平面的空间，至多 2–3 层遮挡，不依赖写实体积、景深和真实投影。细线、点刻、短划与叶脉只用于少量局部，避免把所有树、草地与衣服都填成密集精细线描；颗粒是主要材质，细线只是辅助。

### 人物简化规则
有人物时，用 3–5 个主要色块表现头、躯干和肢体，优先小尺度、侧面或背影。以整体姿态表达走路、坐下等动作，不以人体细节表达。
省略五官、手指、发丝、衣褶、纽扣、腰带、鞋带与真实肌肉结构。头发是一整块轮廓；衣服是一个主要形体，仅在辨识必需时保留一件简化配饰。避免写实人体、时装插画人物和精致人物刻画，也不要转换成大眼睛卡通。

### 3. 构图：有色留白与轻巧节奏
让主体呼吸，保留约 45–65% 的低信息区域。纯色纸纹与颗粒背景仍算留白。整体组织像随手铺开的纸上形体，不要像精心搭建的舞台或完整风景画。
减少元素种类与数量，使用 1 个主角、1–3 组辅助形体；人物默认占画面高度约 6–12%，主题需要时可调整。形体间距要有大小变化，不平均分布。用偏心位置、松散错落、局部裁切和不完全对称产生自然节奏。
默认避免两侧树木夹住主体、四角装饰包围主体、正中人物、蜿蜒道路通向人物、完整铺满的前景草地，以及前中后景过度完整的风景叙事。不要为了“松弛”添加更多风吹叶片；优先删除装饰和连接元素，扩大形体之间的空间。
为新主题选择以下一种结构，并重新安排各元素：
- 疏朗纵向：少量主体沿偏心竖向错落，间距不均，另一侧保持空场。
- 小主体大空间：少量小形体置于宽阔有色场，避免机械居中。
- 边缘生长：形体从一两侧进入，中央或上方留出开阔空间。
- 横向节奏：大中小形体沿舒缓弧线或起伏组织，疏密交替。
不要固定使用花草装饰所有主题。主题本身应清晰可辨：机器用线纹零件、城市用简化建筑、运动用姿态节奏；植物只在叙事需要时出现。
默认单幅竖版 3:4；用户指定尺寸、横版或用途时服从其要求，并保持空间关系。不要把多张参考的拼贴展示方式误当成每次都要四宫格。

### 4. 字体与排版：克制的书刊气质
大多数参考图没有文字；仅带文字封面提供较明确的排版依据。默认纯插画，不主动添加标题、日文、署名、出版信息或假文字。
用户要求文字时，使用用户给定的准确文案：中文优先宋体/明朝体气质，英文优先经典书刊衬线体，必要时使用干净简朴的无衬线大标题。字重适中，文字用深墨绿或暖黑，保持清楚的标题与注释层级，不超过两种字体气质。
把文字放在安静的留白区，与插画共享对齐线，留足边距，不覆盖密集纹理。拒绝书法狂草、泡泡字、霓虹描边、立体字和大量装饰字体。长文不要硬塞进图；保留短标题或按用户要求留空。若文字生成不准确，重试或如实说明，不声称精确排版已实现。

## 执行流程
1. 读取主题、必须出现的元素、用途、尺寸与文字。只有缺失信息阻止创作时才询问；否则直接生成一张。
2. 把主题提炼为一个可辨认的视觉叙事，确定 1 个主角与少量辅助元素。明确本次原创的动作、尺度和空间关系。
3. 从色标选一组主辅色，并选一种构图结构。让主题改变内容，让本 Skill 保持材质、颜色关系与空间节奏。
4. 调用可用的图片生成工具实际生成图片，遵守该工具的调用与展示要求。默认不提供原图作构图参考；本 Skill 的文字规范已足够。若用户再次附图并要求视觉参照，只提取色彩/材质，不把原图作为要修改或复制的画面。
5. 生成提示词使用下方骨架，填入具体内容，不能仅粘贴风格关键词。不要把完整配色表或分析文字印到图上。
6. 查看结果，核查主体是否清楚、色彩是否来自本体系、形体是否平面、印刷颗粒是否明显、低信息区域是否约占 45–65%、布局是否松散而不形成装饰包围、人物是否足够简化、文字是否正确以及构图是否原创。能够查看输出且出现明显偏离时针对缺陷重试；若无法查看则不宣称已视觉核验。没有运行生成工具时不声称已生成图片。
7. 交付图片，必要时附一行说明。不自动制作示例集、PPT 或额外文件。

## 生成提示词骨架

## 跨主题转译检查
- 人工智能：用纸面形体与细线连接表现知识协作，不能把主题替换成无关花束。
- 雨中的城市：用矿物蓝空间、米白建筑和砖红点色表达城市，保留疏朗天空。
- 烹饪：用金黄背景、简化器皿与植物绿食材表达操作动作，禁止写实食物摄影。
上述仅作泛化检查，不固定输出相同构图或额外示例图。
